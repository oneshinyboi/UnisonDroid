# UnisonDroid

An Android client for [Unison](https://github.com/bcpierce00/unison) file synchronization,
syncing files between the device and remote hosts over SSH.

## Status

Early development. Not yet functional.

## Building

Requires JDK 17+ and an Android SDK with platform 36 (set `sdk.dir` in
`local.properties` or export `ANDROID_HOME`).

    ./gradlew :app:assembleDebug
